# Deck — a CSS framework in one file.
#
# Served from the root of the host, the only place a crawler looks for
# robots.txt, so every line below is read and has an effect.
#
# Everything here is public documentation for an open source project. There is
# nothing to protect, so nothing that carries prose is disallowed.
#
# AI crawlers are deliberately allowed. Deck's audience is developers, many of
# whom meet a framework through an assistant rather than a search box, and
# being read accurately by those crawlers is the point of it. Blocking them
# buys nothing and guarantees the one outcome worse than not being cited:
# being described from an invented memory of the API.
#
# EVERY GROUP CARRIES ITS OWN RULES
# A crawler obeys only the group that names it. The * group is for crawlers no
# group names, and nobody else (RFC 9309, section 2.2.1), so a rule written only
# under * never reaches Googlebot, GPTBot, or any other agent listed here. Each
# group repeats the two Disallow lines for that reason. tools/site.mjs fails the
# build if any group's rules differ from the * group's, and writes the Sitemap
# line from the site's base URL.
